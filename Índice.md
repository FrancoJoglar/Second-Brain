## 🌱 Tips de Uso Rápido

| Acción | Cómo |
|--------|------|
| **Nueva nota del día** | `Ctrl+N` → fecha + lugar |
| **Buscar rápido** | `Ctrl+O` y escribís |
| **Link a otra nota** | `[[nombre de nota]]` |
| **Link a archivo** | Arrastrar con `Ctrl` presionado |
| **Tabla rápida** | `\|col1\|col2\|` + Tab (con Advanced Tables) |
| **Checklist** | `- [ ] tarea` |
| **Subir cambios** | `Ctrl+P` → `Git: Pull` (traer mis notas) |
| **Auto-sync** | Cada 15 min se sincroniza solo |
